# Agent Instructions

Use Australian English.

This repo is a lightweight Film Club documentary planning workbench. It is a static, browser-only Markdown builder toolkit, not a heavy governance system and not a generic movie-review site.

## Working Style

- Keep the site multi-page. Do not collapse it into a one-page index-only site.
- Prefer clear builder pages that produce copyable and downloadable `.md` files.
- Keep prompts compact in the UI. Put optional depth into the generated Markdown.
- Label drafts clearly and keep source/date/provenance fields visible where useful.
- Keep public/private boundaries explicit.
- Do not publish private notes, raw local file paths, sensitive contacts, protected locations, permissions, or unfinished claims without deliberate human review.

## Core Outputs

Builder outputs should help a film-club organiser, researcher, discussion host or future agent understand:

- what the film is claiming
- what is shown, implied, omitted or uncertain
- which scenes carry the strongest evidence
- which source trails need checking
- who made the film, who is represented, and who is missing
- what questions belong to filmmakers, subjects, critics, local experts or the audience
- what is useful for public discussion, article drafts, future episodes, screenings, workshops, research trails and agent handoffs
