Workflow

Six stages, one cause-and-effect path.

The public site shows the pathway in normal HTML pages. The repo still keeps Markdown source notes for agents and maintenance.

Lane 01 Foundation

Film profile, then theme and motif, so the work has a frame before the research expands.

 Lane 02 Research map

Research angle, source trail, character/subject and interview questions.

 Lane 03 Scene analysis and assembly

Scene analysis first, then the run sheet that compiles scenes into a working film order.

 Lane 04 Festival entry

Compare FilmFreeway options by category fit, fees, deadlines, rights, materials and red flags.

 Lane 05 Viewing and follow-up

Viewing notes, event notes and follow-up actions once the public or group context is clear.

 Lane 06 Agent handoff

Package the exact outputs, boundaries and next task once the working trail is clear.
