Loose project terrain

Pick the path that helps. Ignore the rest.

This is an open-source map of possible documentary work, not a production mandate. Start with the form that matches what you are doing now, loop back later or skip whole areas.

Gather

Trace

Shape

Notice

Share

Builder trailheads
